## 🚀 Como Publicar Gratuitamente no GitHub Pages

1. Crie um novo repositório no seu perfil do [GitHub](https://github.com/new) com o nome que desejar (ex: `casamento` ou `breno-e-noiva.github.io`).
2. Abra o terminal nesta pasta e envie os arquivos:
   ```bash
   git init
   git add .
   git commit -m "Meu site de casamento"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git
   git push -u origin main
   ```
3. No GitHub, acesse o repositório, vá em **Settings** > **Pages**.
4. Em **Branch**, selecione `main` e a pasta `/ (root)`. Clique em **Save**.
5. Pronto! Em 1 minuto o site estará no ar no endereço:
   `https://SEU_USUARIO.github.io/casamento`
